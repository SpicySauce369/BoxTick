# 웹사이트 디자인서

## 프로젝트명
**박스틱 (BoxTick)** — 포켓몬카드 시세 조회 & 카드팩 개봉 시뮬레이터

---

## 1. 디자인 컨셉

- **미니멀**: 장식을 최소화하고, 시세·그래프·게시글 같은 정보가 가장 먼저 읽히게 한다.
- **정보 우선**: 숫자(시세, 상승률)와 그래프를 화면의 중심에 둔다.
- **일관성**: 색상·간격·컴포넌트를 규칙화해서 모든 페이지에 동일하게 적용한다.
- **테마 지원**: 라이트 / 다크 두 가지 테마를 제공한다.

## 2. 테마 설계 (라이트 / 다크)

| 항목 | 내용 |
|------|------|
| 기본 테마 | 라이트 |
| 전환 방법 | 헤더의 테마 토글 버튼 |
| 설정 유지 | 선택한 테마를 `localStorage`에 저장해 다음 방문에도 적용 |
| 구현 방식 | CSS 변수 (`:root` = 라이트, `[data-theme="dark"]` = 다크) |

- 모든 색상은 CSS 변수로만 사용하고, 테마 전환 시 `data-theme` 속성만 바꾼다.
- 차트(Chart.js)의 눈금·글자 색도 현재 테마 값에 맞춰 다시 그린다.
- 다크 테마는 순수한 검정(#000) 대신 짙은 회색 계열을 사용해 대비가 과하지 않게 한다.

## 3. 컬러 팔레트

| 용도 | 변수명 | 라이트 | 다크 |
|------|--------|--------|------|
| 배경 | --bg | #FFFFFF | #121214 |
| 면(카드·표) | --surface | #F7F7F8 | #1C1C1F |
| 테두리 | --border | #E4E4E7 | #2E2E33 |
| 본문 글자 | --text | #18181B | #F4F4F5 |
| 보조 글자 | --text-muted | #71717A | #A1A1AA |
| 강조(포인트) | --accent | #FFCB05 | #FFCB05 |
| 상승 | --up | #E5484D | #FF6369 |
| 하락 | --down | #3E63DD | #6E8DF2 |

- **포인트 컬러**는 포켓몬을 연상시키는 노랑 하나만 사용한다. (로고, 선택 상태, 포커스 표시)
- **기본 버튼**은 본문 글자색을 배경으로 쓰는 단색 버튼으로 하고, 장식 색은 쓰지 않는다.
- **상승/하락**은 국내 주식·시세 서비스 관례에 맞춰 상승 = 빨강, 하락 = 파랑으로 한다.

## 4. 타이포그래피

| 구분 | 크기 | 굵기 |
|------|------|------|
| 페이지 제목 (h1) | 28px | 700 |
| 섹션 제목 (h2) | 22px | 600 |
| 본문 | 16px | 400 |
| 보조 텍스트 | 14px | 400 |

- 글꼴: **Pretendard** (대체: 시스템 기본 sans-serif)
- 시세·가격 숫자는 `font-variant-numeric: tabular-nums`를 적용해 자릿수가 정렬되도록 한다.
- 가격은 천 단위 쉼표와 `원` 단위를 함께 표기한다.

## 5. 레이아웃 규칙

- 콘텐츠 최대 너비 **1080px**, 가운데 정렬
- 간격은 **8px 단위** (8 / 16 / 24 / 32)
- 모서리 둥글기 **8px**, 그림자는 쓰지 않고 **1px 테두리**로 구분
- 반응형 기준

| 구간 | 화면 너비 | 카드 그리드 |
|------|----------|-----------|
| 데스크톱 | 1024px 이상 | 4열 |
| 태블릿 | 768 ~ 1023px | 3열 |
| 모바일 | 767px 이하 | 2열 |

## 6. 공통 컴포넌트

| 컴포넌트 | 설명 |
|----------|------|
| 헤더 | 로고 / 메뉴(시세·커뮤니티) / 검색 / 테마 토글 / 로그인·마이페이지 |
| 푸터 | 서비스명, 간단한 안내 문구, 이미지 출처 및 비공식 사이트 안내 문구 |
| 버튼 | 기본(단색) / 보조(테두리만) / 위험(삭제용, 빨강 계열) |
| 입력 폼 | 테두리 입력창, 포커스 시 포인트 컬러 테두리 |
| 카드 썸네일 | 이미지 + 카드명 + 현재 시세 + 상승률 |
| 게시판 표 | 번호 / 제목 / 작성자 / 날짜 / 조회수 |
| 배지 | 희귀도, 공지, 카테고리 표시 |
| 탭 | 그래프 기간 선택(1주 / 1개월 / 3개월), 게시판 카테고리 |
| 알림 | 저장·삭제 결과를 알려주는 간단한 토스트 메시지 |
| 요약 카드 | 최고가·최저가·평균가, 평가금액·손익처럼 핵심 수치를 보여주는 카드 |

- 헤더의 **관리자 메뉴**는 관리자 계정으로 로그인했을 때만 표시한다.

## 7. 페이지별 화면 구성

### 7-1. 메인 (index.html)

```
┌──────────────────────────────────────────┐
│ BoxTick   시세  커뮤니티   [검색]  ◐  로그인 │
├──────────────────────────────────────────┤
│  카드 시세를 한눈에                          │
│  [ 카드 이름으로 검색                 🔍 ]   │
├──────────────────────────────────────────┤
│  ▲ 많이 오른 카드                           │
│  [카드] [카드] [카드] [카드]                  │
│  최근 등록 카드                             │
│  [카드] [카드] [카드] [카드]                  │
├──────────────────────────────────────────┤
│  최신 게시글 / 공지                          │
│  · 제목 ................ 작성자  날짜        │
└──────────────────────────────────────────┘
```

### 7-2. 카드 검색 (cards.html)
- 상단: 검색창 + 필터(세트, 희귀도)
- 본문: 카드 썸네일 그리드, 하단 페이지 번호
- 각 카드: 이미지, 이름, 현재 시세, 상승률(▲ / ▼)

### 7-3. 카드 상세 (card.html)

```
┌──────────────────────────────────────────┐
│ [카드 이미지]   카드명                 ♡ 찜  │
│                세트 · 희귀도                │
│                현재 시세  125,000원 ▲ 8.2%  │
│                팩 환산  팩 약 N개 값         │
├──────────────────────────────────────────┤
│  [1주] [1개월] [3개월]                     │
│  ┌────────────────────────────────────┐   │
│  │        가격 변동 그래프 (라인)         │   │
│  └────────────────────────────────────┘   │
│  최고가      최저가      평균가              │
├──────────────────────────────────────────┤
│  세트 정보: 박스 정가 · 박스 시세 · 상승률     │
└──────────────────────────────────────────┘
```

- 로그인한 회원에게는 `♡ 찜` 버튼과 함께 `포트폴리오에 추가`(선택), `거래가 제보`(선택) 버튼을 표시한다.
- 비회원이 이 버튼을 누르면 로그인 안내를 보여준다.

### 7-4. 게시판 (board.html / post.html / write.html)
- 목록: 카테고리 탭(전체·자유·시세 정보·개봉 자랑·공지) + 표 + 검색 + 페이지 번호
- 상세: 제목, 작성자·날짜·조회수, 본문, 댓글 목록, 댓글 입력창
- 글쓰기: 카테고리 선택, 제목, 본문, 등록 버튼 (로그인 필요)
- 공지 카테고리는 관리자에게만 선택지로 표시한다.

### 7-5. 로그인 / 회원가입
- 화면 가운데 하나의 입력 카드만 배치하고 불필요한 요소는 두지 않는다.
- 입력 오류는 해당 입력창 아래에 짧은 문구로 안내한다.

### 7-6. 마이페이지
- 탭으로 구분: 내 정보(아이디 확인, 닉네임·비밀번호 수정) / 찜한 카드 / 내가 쓴 글 / 내 포트폴리오(선택)

**내 포트폴리오 (선택)**

```
┌──────────────────────────────────────────┐
│ [내 정보] [찜] [내가 쓴 글] [포트폴리오]       │
├──────────────────────────────────────────┤
│ 총 평가금액     총 매입금액     손익           │
│ 1,250,000원   1,000,000원   ▲ 250,000원   │
│                              (+25.0%)    │
│                                [+ 카드 추가] │
│ ┌────────────────────────────────────┐   │
│ │ 카드 │ 수량 │ 매입가 │ 현재 시세 │ 손익    │   │
│ │ …                                   │   │
│ └────────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

- 상단 요약은 요약 카드 컴포넌트를 사용한다.
- 손익은 상승이면 ▲ + `--up`, 하락이면 ▼ + `--down`으로 표시한다.
- 카드를 누르면 해당 카드의 상세 페이지로 이동한다.

## 8. 그래프 디자인 (Chart.js)

- 형태: 라인 차트, 부드러운 곡선 대신 직선 연결로 정확한 값 표현
- 선 색상: 선택 기간의 변동이 상승이면 `--up`, 하락이면 `--down`
- 마우스를 올리면 날짜와 가격이 툴팁으로 표시
- 하단에 최고가 / 최저가 / 평균가를 요약 카드로 표시
- 눈금선은 `--border`, 글자는 `--text-muted`를 사용해 테마 전환에 대응

## 9. 사용자 화면과 관리자 화면의 차이

| 구분 | 사용자 화면 | 관리자 화면 |
|------|-----------|-----------|
| 레이아웃 | 상단 헤더 + 콘텐츠 | 좌측 사이드바 + 콘텐츠 |
| 구성 | 카드 그리드, 그래프, 게시글 | 표(Table) 중심의 관리 화면 |
| 표시 | 일반 헤더 | 상단에 `ADMIN` 배지 표시 |
| 주요 메뉴 | 시세, 커뮤니티, 마이페이지 | 카드·시세 관리, 세트 관리, 회원 관리, 게시글·공지 관리 |

### 관리자 화면 예시

```
┌────────┬─────────────────────────────────┐
│ ADMIN  │  카드 · 시세 관리                  │
│        │  [+ 카드 등록]        [검색]       │
│ 카드   │  ┌──────────────────────────────┐ │
│ 세트   │  │ ID │ 카드명 │ 세트 │ 시세 │ 관리 │ │
│ 회원   │  │ …                            │ │
│ 게시글 │  └──────────────────────────────┘ │
└────────┴─────────────────────────────────┘
```

## 10. 상태별 화면 처리

| 상태 | 표시 방식 |
|------|----------|
| 로딩 | 간단한 로딩 문구 또는 회색 자리표시 |
| 데이터 없음 | "검색 결과가 없습니다" 등 짧은 안내 문구 |
| 오류 | 오류 내용을 알리는 토스트 메시지 |
| 이미지 로드 실패 | 대체(자리표시) 이미지를 표시 |
| 로그인 필요 | 로그인 페이지로 이동 안내 |
| 권한 없음 | 관리자 페이지 접근 시 접근 불가 안내 |

## 11. 접근성

- 키보드 사용 시 포커스 위치를 포인트 컬러 테두리로 표시한다.
- 상승/하락은 색뿐만 아니라 **▲ / ▼ 기호를 함께** 표기한다.
- 이미지에는 대체 텍스트(alt)를 넣는다.
- 라이트·다크 모두에서 글자와 배경의 명암 대비가 충분하도록 색을 정했다.

## 12. 이미지 및 출처 표기

- 카드·박스 이미지는 외부 카드 데이터 API의 이미지 주소를 불러와 표시한다.
- 이미지가 없거나 불러오지 못하면 테두리만 있는 회색 자리표시 이미지를 보여준다.
- 모든 페이지 푸터에 아래 취지의 문구를 표기한다.

## 13. 카드팩 개봉 시뮬레이션 화면

- 기획 단계의 부가 기능으로, **구현 여부는 고려 중**이다.
- 구현하는 경우 위의 컬러·컴포넌트 규칙을 그대로 따르는 별도 화면으로 설계한다.
