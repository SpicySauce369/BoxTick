# 웹사이트 기획서

## 프로젝트명
**박스틱 (BoxTick)** — 포켓몬카드 시세 조회 & 카드팩 개봉 시뮬레이터

---

## 1. 프로젝트 개요
포켓몬카드의 시세를 조회·비교하고, 회원들이 정보를 나누는 커뮤니티 게시판과
가상으로 카드팩을 주문하고 개봉하는 시뮬레이션을 제공하는 웹사이트.
(선택 기능으로, 보유 카드를 등록해 평가금액과 손익을 확인하는 포트폴리오 기능도 제공한다.)

## 2. 기획 배경 및 목적
- 포켓몬카드 수집 인구가 늘면서 카드 시세를 한곳에서 확인하려는 수요가 있음
- 실물 카드팩 구매는 비용 부담이 크므로, 가상으로 "주문 → 배송 → 개봉"의 과정을 즐기는 대리만족 콘텐츠 제공
- 최근 인기 있는 배달 시뮬레이션 앱처럼, 단순한 조작만으로 기대감과 재미를 주는 경험 설계
- 목적: 시세 정보 + 커뮤니티 + 가벼운 재미를 하나의 서비스로 결합

## 3. 타깃 사용자
| 구분 | 설명 |
|------|------|
| 수집가 | 보유·희망 카드의 시세를 확인하고 싶은 사용자 |
| 입문자 | 카드 가치를 잘 몰라 정보가 필요한 사용자 |
| 라이트 유저 | 직접 구매 대신 가상 개봉의 재미를 원하는 사용자 |

## 4. 핵심 기능

### 4-1. 회원 기능
- 회원가입 / 로그인 / 로그아웃
- 마이페이지 (내 정보 수정, 내가 쓴 글, 찜한 카드, 내 포트폴리오(선택), 보유 포인트·획득 카드 컬렉션(시뮬레이션 구현 시))

### 4-2. 시세 조회 기능
- 카드 목록 검색 (이름, 세트, 희귀도)
- 카드 상세 페이지 (이미지, 정보, 현재 시세, 시세 변동 이력)
- **가격 변동 그래프**: 라인 차트, 기간 선택(1주 / 1개월 / 3개월), 최고가·최저가·평균가 표시
- **정가(소비자 원가) 대비 상승률**: 세트별 **박스 정가**와 박스 시세를 비교해 상승 폭을 표시
- **팩 환산**: 박스 정가 ÷ 박스당 팩 수량으로 팩 정가를 계산하고, 카드 시세가 팩 몇 개 값인지 함께 표시
- 박스 시세도 관리자가 날짜별로 등록
- 관심 카드 등록(찜)

**시세 수집 방식**
| 구분 | 방식 | 우선순위 |
|------|------|:------:|
| 기본 | 초기 샘플 데이터(시드) + 관리자의 날짜별 시세 등록 | 필수 |
| 확장 | 회원이 거래가를 제보하면 평균을 내어 반영 | 선택 |
| 확장 | 스크립트를 이용한 주기적 자동 수집 (실패 시 기존 DB 데이터 유지) | 선택 |

※ 외부 사이트의 크롤링은 이용 약관과 차단 정책에 따라 제한될 수 있으므로, 서비스는 자동 수집 없이도 정상 동작하도록 설계한다.

### 4-3. 게시판 기능
- 자유게시판 / 시세 정보 공유 / 개봉 자랑 게시판 / 공지 (관리자 전용 작성)
- 글 작성·조회·수정·삭제, 댓글
- 검색, 페이지네이션

### 4-4. 카드팩 개봉 시뮬레이션 (여유 시 구현)
- 가상 포인트로 카드팩 "주문" → 배송 진행 상태 표시(주문 접수 → 배송 중 → 도착)
- 도착한 팩 개봉 → 확률에 따라 카드 획득
- 획득 카드는 내 컬렉션에 저장, 희귀 카드 획득 시 연출 효과
- 포인트는 출석·활동으로 획득하는 가상 재화이며, 실제 결제는 없음

### 4-5. 내 포트폴리오 (선택)
- 보유 중인 카드를 등록한다. (카드, 수량, 개당 매입가)
- 현재 시세 기준 **평가금액**, 총 매입금액 대비 **손익·수익률**을 표시한다.
- 카드별 현재 시세와 손익을 목록으로 보여준다.
- 본인의 포트폴리오만 조회·수정할 수 있으며 다른 회원에게는 공개하지 않는다.
- ※ 개봉 시뮬레이션의 "내 컬렉션"(가상으로 획득한 카드)과 달리, 실제로 보유한 카드를 기록하는 기능이다.

## 6. 메뉴 구조

```
메인
├─ 시세 조회
│   ├─ 카드 검색/목록
│   └─ 카드 상세
├─ 커뮤니티
│   ├─ 자유게시판
│   ├─ 시세 정보 공유
│   ├─ 개봉 자랑
│   └─ 공지
├─ 카드팩 개봉 (시뮬레이션)
│   ├─ 팩 주문
│   ├─ 배송 현황
│   └─ 내 컬렉션
├─ 로그인 / 회원가입
├─ 마이페이지
│   ├─ 내 정보 / 내가 쓴 글 / 찜
│   └─ 내 포트폴리오 (선택)
└─ 관리자 페이지 (관리자 전용)
    ├─ 카드/시세 관리
    ├─ 카드팩 관리
    ├─ 회원 관리
    └─ 게시글/공지 관리
```

## 7. 주요 사용자 시나리오
1. **시세 확인**: 메인 → 카드 검색 → 상세 페이지에서 시세 및 변동 확인
2. **커뮤니티 이용**: 로그인 → 게시판 글 작성 → 다른 회원이 댓글 작성
3. **카드팩 개봉**: 로그인 → 포인트로 팩 주문 → 배송 완료 알림 → 개봉 → 컬렉션 저장
4. **관리자 운영**: 관리자 로그인 → 신규 카드·시세 등록 → 부적절한 게시글 삭제 → 문제 회원 정지
5. **내 포트폴리오 (선택)**: 로그인 → 보유 카드 등록(수량·매입가) → 평가금액과 손익 확인

| 우선순위 | 내용 |
|---------|------|
| 필수 | 회원(가입/로그인), 게시판(CRUD+댓글), 시세 조회, 가격 변동 그래프, 정가 대비 상승률, 관리자 페이지 |

## 9. 기술 조건
- 웹서버: Node.js
- 데이터베이스: SQLite
- 사용자 / 관리자 권한 구분 적용
- 화면은 HTML/CSS/JavaScript로 구성하고 REST API(fetch)로 서버와 통신하며, 로그인은 세션 방식을 사용한다.
- 라이트 / 다크 테마를 지원한다. (기본 라이트, 미니멀 디자인)
- 카드·박스 이미지는 공개 카드 데이터 API(예: pokemontcg.io, TCGdex)의 이미지 주소를 DB에 저장해 외부 URL로 불러온다.
- 이미지가 없거나 불러오지 못하면 대체(자리표시) 이미지를 표시한다.
- 카드 저작권은 각 권리자(The Pokémon Company 등)에게 있으므로, 푸터에 출처 및 비공식 사이트임을 알리는 문구를 표기한다.

## 10. 기대 효과
- 카드 정보와 시세를 한곳에서 확인할 수 있어 수집가의 편의 증대
- 커뮤니티를 통한 정보 공유 및 소통 활성화
- 가상 개봉 체험으로 부담 없이 즐기는 재미 요소 제공
